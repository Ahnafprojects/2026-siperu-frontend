# SiPeru Frontend

Frontend dashboard untuk manajemen peminjaman ruangan. Aplikasi ini menampilkan ringkasan statistik, status ruangan, daftar peminjaman, serta modal untuk membuat dan mengelola peminjaman.

**Teknologi**
- React 19 + TypeScript
- Vite 7
- Tailwind CSS 4
- Framer Motion
- Lucide React

**Instalasi**
1. `npm install`

**Env**
- Salin contoh konfigurasi: `cp .env.example .env`
- Isi nilai yang diperlukan di `.env`

Variabel yang tersedia:
- `VITE_API_BASE_URL` = base URL backend (contoh: `http://localhost:5250/api`)

**Menjalankan**
1. Development: `npm run dev`
2. Build: `npm run build`
3. Preview build: `npm run preview`
4. Lint: `npm run lint`
